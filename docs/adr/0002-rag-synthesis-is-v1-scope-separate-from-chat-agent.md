# RAG 汇总(KnowledgePanel)是 v1 范畴,与聊天 Agent 分立

阶段 1 spec §6 定义的第五组件 KnowledgePanel(点知识点 → AI 汇总其 tag/backlink 关联笔记 + 引用溯源)属于 v1 范畴。工作区 v1 设计与代码中暂缺此组件,属范围缺口,需补建——不是被聊天 Agent 吸收。

聊天 Agent(自由 NL 驱动工作区工具调用)是独立、更难的范畴,v1 仅留 UI 留位。两者刻意分立:汇总是确定性的「点节点→综合关联」;聊天是自由 NL。后期聊天 Agent 会把「汇总」包装成一个可调 tool,但不应因此把汇总延后到 Agent 里一起造——那样会在一个更难的范畴里同时发明两件事,且 v1 的图谱(无汇总)只剩浏览,坐实 user3 的「玩具」风险。

取舍:把汇总纳入 v1 = 重开此前「告一段落」的进度。接受,因为阶段 1 验证目标「用户真用图谱 + AI 摘要(对冲玩具风险)」缺了「AI 摘要」一半即不成立。
