# 拾阅 W0 Spike 体验反馈 — 用户2：李姐（产品经理/微信读书用户）

### 评分(1-5 分,5 最好)

| 维度 | 分数(1-5) | 说明 |
|---|---|---|
| 1. 打开速度 | 2 | 我试了一份60多页的行业报告PDF，打开之后明显要等一会儿才渲染完，风扇都转了。我MacBook Air才8G内存，感觉这个插件挺吃资源的。相比之下Mac自带的Preview基本秒开，差距比较大。 |
| 2. 滚动流畅度 | 2 | 滚动的时候能感觉到不太跟手，最难受的是右边滚动条会抖——就是你拖着滚动条往下拉，它会自己跳一下又回来，有点像页面在重新计算高度。读长报告的时候这个问题挺影响沉浸感的，我经常要翻来翻去对比前后内容，滚动条抖动让我很难快速定位到刚才看的位置。 |
| 3. 文字选择可用性 | 2 | 基本能选中文字，但选区框经常对不准。英文白皮书里选一段话，选区的蓝色框左右跟实际文字有偏移，看着别扭。而且英文字号小的时候，选区框上下也对不齐，框比字高出来一截或者矮一截，视觉上很粗糙。 |
| 4. 中文选区质量(若测了中文) | 1 | 这个是我最想吐槽的。我主要读中文PDF，选区问题太多了：(1) 选到一行末尾的时候，经常会把下面好几行也一起选进来，我明明只想选一句话，结果框了一大段；(2) 更离谱的是选区拖到靠近页面边缘的时候，整页内容都被选中了，完全不可控；(3) 中文的选区框跟文字的贴合度也不好，框和字之间有明显的错位。对我来说中文选区基本不可用，没办法精确地高亮我想标注的内容。 |
| 5. 总体体验 | 2 | 能看出来开发者想在Obsidian里做一个原生的PDF阅读体验，方向是对的。但现在这个版本离"能用"还有距离，离"好用"差得更远。作为一个每天要读报告的人，我暂时没法把它当主力工具。 |

### 开放反馈

**最让你觉得好用的地方？**

方向感是对的——能在Obsidian里直接打开PDF这件事本身就有价值。我之前的工作流是：Preview里读PDF → 截图 → 粘到Obsidian笔记里，很割裂。如果拾阅能做好，确实能省掉这个来回切换的成本。另外AI侧边栏的概念我蛮感兴趣的，如果能一边读报告一边问AI"这段的核心观点是什么"，对我做竞品分析会有帮助。

**最让你不爽的地方？**

三个点，按难受程度排序：

1. **中文选区问题**——这个直接决定了我能不能用。我读的90%是中文报告，选区不准意味着我没法正常做高亮标注，那这个阅读器对我来说就只是一个"能看但不能标"的东西，跟Preview没区别甚至还不如。行尾误选和边缘误选整页的问题特别严重，感觉像是文字坐标计算有bug。

2. **打开方式太麻烦**——每次都要Cmd+P调命令面板才能打开PDF，这个操作路径太长了。我在Obsidian里双击一个PDF文件不就应该直接打开吗？而且每次打开都会新开一个view区域，我的屏幕本来就不大（Air 13寸），开两三个PDF之后工作区就乱了。应该像浏览器一样，在同一个区域用标签页的方式打开，这才符合Obsidian的操作习惯。

3. **界面太简陋**——整体视觉上比较"工程版"的感觉，没有什么阅读器该有的质感。微信读书的阅读体验虽然是另一个品类，但至少在排版、翻页、视觉舒适度上是下了功夫的。拾阅现在的界面让我觉得"这是给开发者自己用的"，不像一个面向普通用户的产品。

**你会用它替代现在的 PDF 阅读/笔记方式吗？为什么？**

现阶段不会。我现在的方式虽然割裂（Preview + 截图 + Obsidian），但至少每个环节都是稳定可用的。拾阅目前在"阅读"这个最基础的环节上体验还不够——大文件卡、滚动抖、选区不准，这三个问题同时存在的话，我没有动力切换。

我愿意持续关注，如果后续版本能做到：(1) 中文选区准确率达到90%以上；(2) 60页PDF在8G内存设备上秒开、滚动不抖；(3) 双击PDF直接打开+标签页模式——满足这三点我就愿意切过来试用。

**你愿意为这样一个工具(加上未来的 AI 高亮/笔记)付费吗？心理价位？**

说实话，仅凭"PDF阅读器+高亮"我不会付费，因为Preview免费就够用了。加上AI辅助阅读的话……我会考虑，但要看AI能做到什么程度。如果只是总结和翻译，市面上太多免费替代了（Kimi、豆包都能做）。

如果AI能做到这种程度我愿意付费：比如我高亮了一段竞品的功能描述，AI能自动帮我跟我之前高亮的其他竞品内容做对比分析，甚至生成竞品对比表——这种跟Obsidian笔记体系深度打通的能力，才是我愿意掏钱的点。

心理价位：买断制¥98-128，或者订阅制¥12-15/月。超过这个价格我会犹豫，毕竟MarginNote买断也就两百多，功能成熟得多。


### 其他

建议做成可视化知识图谱的模式。这个知识图谱完全由AI驱动，人能通过放大或缩小视野来获取不同广度的视角。若想获取这个领域的全局视野，就缩小视角；若想了解某本书的某个知识点，就放大视角，点击这个点，从弹出的子页中可以浏览所有关于该知识点的关键信息。我记得obsidian本身就有这个能力？

- **用 Obsidian 多久了？** 大概1年，主要用来做产品笔记、竞品分析、需求文档整理。装了十几个插件，日历、看板、模板这些基础的都有，但不太折腾复杂的工作流。
- **你现在怎么读 PDF + 做笔记？** 中文行业报告一般用微信读书（能搜到的话）或者Mac Preview打开，读的时候把重要内容截图粘到Obsidian里，再手动加批注。英文白皮书偶尔用MarginNote，但觉得MarginNote学习成本有点高，很多功能用不上。整体流程比较碎片化，一直想找一个"在Obsidian里一站式搞定"的方案。
- **你的设备配置？** MacBook Air M1，8GB内存，256GB存储。日常开着Obsidian + 飞书 + Chrome（十几个标签页），内存基本常年吃满。
