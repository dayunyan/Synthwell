# 拾阅 / Shiyue — 测试者指南(W0 spike)

> 感谢你测试!这是一个 Obsidian 插件的**早期验证原型**,目标是验证「在 Obsidian 里读 PDF + 选中文字」的体验能不能用。**它不是成品**——只有 PDF 阅读 + 文字选择,没有 AI 对话、高亮持久化、导入等功能。请基于「阅读 + 选文字」这个核心体验评分。

## 你需要准备
- 用 Obsidian **6 个月以上**
- 平时在电脑上读 PDF
- 约 **30 分钟**时间

## 安装(约 3 分钟)
1. 下载这 4 个文件:`main.js`、`manifest.json`、`pdf.worker.min.mjs`、`styles.css`
2. 在你的 Obsidian vault 里,打开文件管理器,找到 `.obsidian/plugins/` 文件夹(如果没有就新建一个 `plugins` 文件夹)
3. 在 `plugins/` 下新建文件夹 `shiyue`,把 4 个文件放进去
4. Obsidian → 设置 → 第三方插件 → 关闭安全模式(若提示)→ 在列表里找到「拾阅 / Shiyue」→ 打开开关启用
5. 如果启用时报错,把错误截图 + Obsidian 版本(设置 → 关于)发回来

## 测试任务(约 20 分钟)
打开任意一个 PDF(最好含中文正文,比如中文论文/报告)。然后:

1. **打开**:命令面板(`Cmd/Ctrl+P`)→ 搜「拾阅: 打开 PDF」→ 选那个 PDF
2. **阅读体验**:打开快不快?上下滚动顺不顺?
3. **选文字**(中文和英文都试):拖选一段文字——能选中吗?选中位置和字形对得上吗?
4. **大文件**:如果方便,找一个比较长的 PDF(几十页以上),滚到后面——还能正常渲染吗?有没有卡死/崩溃?
5. **关闭**:关掉这个 PDF 视图——Obsidian 有没有变卡?
